# Persona 3 Reload (P3R v2) — Cinematic Transitions Edition

A faithful, hyper-kinetic web recreation of the **Persona 3 Reload (P3R) Pause / Camp Menu** featuring procedural liquid shader mask transitions and dedicated entry choreography for every single menu option.

---

## 🌊 Cinematic Transitions & Special Effects (v2 Upgrade)

1. **Procedural Liquid Blot Shader (Global Entry)**:
   - Expands outward from the exact screen coordinates of the clicked menu button.
   - Dual-layer sine-wave distorted liquid contour with neon cyan edge stroke (`#16cffb`), soft glow, and deep sea cobalt flood (`#021338`).
   - Accompanied by synthesized water surge swoosh audio.

2. **Concentric Double-Circle Ripple (Global Close)**:
   - Triggered on `ESC` / `Backspace` or Close button.
   - Two concentric water ripples pulse outward with staggered timing, dissolving the sub-screen cleanly back into the calm floating Makoto camp.
   - Accompanied by dual-tone water bubble ripple audio.

3. **Per-Option Dedicated Micro-Choreography**:
   - ⚡ **SKILLS**: Radial detonation of 8 elemental Persona sigils (Slash, Strike, Pierce, Fire, Ice, Elec, Wind, Light) bursting outward, followed by staggered 3D skill card cascade with electric chord audio.
   - 👤 **PROFILE**: High-speed cyan laser scanline sweeps down the S.E.E.S. biometric profile card + live-drawing hexagonal parameter radar chart that springs dynamically from center to stat values + star pop-ins.
   - ⚔️ **PROJECTS**: Diagonal razor-blade gleam slash wipe cuts across the viewport with metallic ring audio + floating additive polygon confetti shards (cyan, white, magenta).
   - 📜 **ACHIEVEMENTS**: Velvet Room Morpho blue butterfly flutters across the screen leaving glowing stardust + kinetic red wax `[COMPLETED]` stamps slam down with screen vibration rumble and bass impact sound.
   - 🤝 **EXPERIENCE**: 3D cascading Tarot cards fan out in perspective across deep water with crystalline Velvet Room harmonic bell chimes.
   - ⚙️ **SYSTEM**: CRT scanline calibration sweep + real-time responsive 20-bar audio frequency visualizer equalizer that bounces dynamically to the soundtrack.

## 🎮 Controls & Navigation
| Key | Action |
| --- | --- |
| `W` / `↑` | Move selection Up |
| `S` / `↓` | Move selection Down |
| `ENTER` / `SPACE` / Click | Open Section with Liquid Blot & Custom FX |
| `ESC` / `BACKSPACE` | Close Section with Double-Circle Ripple |
| `Mouse Move` | Ambient water parallax shift |

## 🚀 How to Run
Double-click `run.bat` or run:
```powershell
powershell -ExecutionPolicy Bypass -File server.ps1
```
Then open `http://localhost:8090/` in your browser!
